# Asset sources

- `jose-luis-pixel.png`: José Luis's existing portrait from his portfolio, reused unchanged with permission as part of the profile update. The reference photos are not included.
- `tech/*.svg`: original brand marks from [Devicon](https://github.com/devicons/devicon), reused from the portfolio's local assets. MIT license in [tech/LICENSE.txt](tech/LICENSE.txt). Expo and Three.js include light-coloured variants for dark backgrounds; their shapes are unchanged. Brand marks belong to their respective owners.
- `profile/*.svg`: the JL / POCKET GitHub edition, generated by [scripts/build_profile.py](../scripts/build_profile.py). The palette, console proportions, lettering, original 24 × 32 character and cartridge design are based on José Luis's own portfolio. The portrait is embedded unchanged in the personal section.
- `projects/*.webp`: the existing cartridge label images from José Luis's public portfolio, copied unchanged. They show Paulitaadiaz, Helementa, Helementa App and Wdtech. Product and company marks belong to their respective owners.
- `fonts/Silkscreen-Regular.ttf` and `fonts/PixelifySans.ttf`: the same open-source type families used in the portfolio, from the [official Google Fonts repository](https://github.com/google/fonts). Both are under the SIL Open Font License; the license files are included alongside. The generator embeds their outlines, not network font requests.
- `tech/gsap.svg`: the GSAP mark, reused from the portfolio's [Simple Icons](https://github.com/simple-icons/simple-icons) asset (CC0). `tech/motion.svg` and `tech/tailwindcss.svg` use the same Devicon source and MIT license as the other technology icons. `motion-dark.svg` adds a light foreground to the unchanged monochrome path for contrast on the dark canvas.

Samuel Rizzon's profile was an initial reference for using SVG in GitHub. The visual system here comes from [JL / POCKET](https://www.joseluisdev.es/en), including its cream hardware, green LCD, project cartridges and personal content. No Samuel artwork or source code is included.

The README uses repository assets rather than third-party badge or statistics services. Its content is based on the published portfolio and CV. It keeps the existing English language and links to the English project pages.

To update the profile:

1. Create a Python virtual environment and install `pip install -r scripts/requirements.txt`.
2. Edit public copy and links in `scripts/profile_content.py`, or the SVG layout in `scripts/build_profile.py`.
3. Run `python3 scripts/build_profile.py` and commit the generated SVGs, README and `PROFILE.md` together.

FontTools is a build-time dependency only. Each SVG includes only the glyphs it uses, so fonts do not depend on the viewer's device. Mobile compositions are selected by `<picture>`. Animations finish within a few seconds and respect `prefers-reduced-motion`. Full image descriptions and a linked [plain-text profile](../PROFILE.md) preserve access to the content without the illustrations.
