# Asset sources

- `jose-luis-pixel.png`: José Luis's existing portrait from his portfolio, reused unchanged with permission as part of the profile update. The reference photos are not included.
- `tech/*.svg`: original brand marks from [Devicon](https://github.com/devicons/devicon), reused from the portfolio's local assets. MIT license in [tech/LICENSE.txt](tech/LICENSE.txt). Expo and Three.js include light-coloured variants for dark backgrounds; their shapes are unchanged. Brand marks belong to their respective owners.
- `profile/*.svg`: original pixel lettering, console, studio and device illustrations generated by [scripts/build_profile.py](../scripts/build_profile.py). The header embeds the existing portrait unchanged. No artwork or source code was copied from another profile.

The visual reference is [Samuel Rizzon's profile](https://github.com/srizzon): animated SVG composition and pixel typography. The illustrations, palette and content here belong to José Luis's own projects.

The README uses repository assets rather than third-party badge or statistics services. Its content is based on the published portfolio and CV. It keeps the existing English language and links to the English project pages.

To update the illustrations, edit the content or drawing functions in `scripts/build_profile.py`, then run `python3 scripts/build_profile.py`. Python's standard library is sufficient. Commit the generated SVGs with the script. The mobile versions use a separate composition selected by `<picture>`; motion is brief and disabled with `prefers-reduced-motion`.
