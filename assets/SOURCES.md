# Asset sources

- `profile/*.svg`: original console and cartridge illustrations generated by [build_profile.py](../scripts/build_profile.py). The cream hardware, green LCD, palette, fonts and 24 × 32 character come from José Luis's [interactive portfolio](https://www.joseluisdev.es/en). No artwork or source code from Samuel Rizzon's profile is included.
- `projects/*.webp`: existing project cover images from José Luis's portfolio, copied unchanged. Product and company marks belong to their respective owners.
- `jose-luis-pixel.png`: the existing portfolio portrait, preserved unchanged. The reference photographs are not included.
- `avatar-github.png`: a new avatar generated from that portrait with the built-in image generation tool. Identity details are retained, with a sage background and framing intended for GitHub's circular crop. See [the generation prompt](avatar-prompt.txt). This file does not change the account's profile picture automatically.
- `fonts/Silkscreen-Regular.ttf` and `fonts/PixelifySans.ttf`: the portfolio's type families, from the [Google Fonts repository](https://github.com/google/fonts), under the SIL Open Font License. License files are included beside the fonts.
- `tech/*.svg`: brand marks reused from the portfolio's local [Devicon](https://github.com/devicons/devicon) assets, under the included [MIT license](tech/LICENSE.txt). Light foreground variants preserve the original shapes for dark backgrounds. `gsap.svg` comes from [Simple Icons](https://github.com/simple-icons/simple-icons), under CC0. Marks belong to their respective owners.

The README is deliberately brief: an introduction, three selected projects, tools and contact links. Its English copy is based on the published portfolio. It does not use remote badge or statistics services.

## Updating

1. Install `scripts/requirements.txt` in a Python virtual environment.
2. Edit copy in `scripts/profile_content.py`, or layouts in `scripts/build_profile.py`.
3. Run `python3 scripts/build_profile.py` and commit the generated SVGs, README and `PROFILE.md` together.

FontTools is a build-time dependency only. SVGs embed local font outlines and images, so they do not depend on external fonts. Mobile compositions use `<picture>`. Animations finish within a few seconds and respect `prefers-reduced-motion`. Images include descriptions, with a matching [plain-text profile](../PROFILE.md) available for reading without the illustrations.

The console character uses three original 24 × 32 pixel poses: rest and two waving frames. It blinks and waves after the screen starts, then returns to rest within 4.8 seconds. The animation is embedded CSS inside the desktop and mobile header SVGs; no JavaScript or external animation service is required. Reduced-motion mode shows the resting pose immediately. See [SVG image restrictions](https://developer.mozilla.org/en-US/docs/Web/SVG/Guides/SVG_as_an_image) and [reduced-motion preferences](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/At-rules/@media/prefers-reduced-motion).
